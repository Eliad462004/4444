## 1. Mining Formula (הכנסה מלחיצה)

```
Coins Per Click =
  (1 + PickaxeLvl×M(pick) + Drill×25×M(drill))   ← בסיס + כלים
  × (1 + 0.1×ReactorLvl)                          ← כור אנרגיה
  × CrystalMult (1 או 2)                           ← קריסטל הכוכב
  × PrestigeCrystalMult (1 + 0.02×💠)              ← קריסטלי יוקרה
  × PrestigeClickBonus (בונוסי כוכבים)             ← מסעות
  × SpecialtyBonus (×1.5 אם נבחרה כרייה)           ← התמחות
  × RushMult (×2 בזמן בונוס אתגר/מתנה)             ← זמני
  × ComboMult (1 + 0.01×קומבו, עד ×2)              ← קומבו
  × EnergyPenalty (×0.25 אם אין אנרגיה)            ← אנרגיה
  × CritMult (×3 אם קריטי)                          ← קריט
```

**✅ אימות מהבדיקה:** בסיס 1 × קומבו 1.01 × קריט 3 = 3.03; עם Lucky כפול = **9.09 בדיוק**.

## 2. Upgrade Cost Formula

```
Cost = BaseCost × ScaleFactor(10^planets) × Growth^CurrentLevel
```

| שדרוג | Base | Growth | Lv1→Lv10→Lv50 |
|---|---|---|---|
| ⛏️ מקוש | 15 | 1.35 | 15 → 304 → 51.7M |
| 🤖 רובוט כורה | 60 | 1.22 | 60 → 361 → 1.06M |
| ⚡ כור | 500 | 1.60 | 500 → 34.4K → 8.9T |
| 🚀 רחפן | 3,000 | 1.28 | 3K → 27.8K → 71.9M |
| 🛠️ מקדחה | 12,000 | 1.40 | 12K → 248K → 4.9T |
| 🛸 צי | 75,000 | 1.35 | 75K → 1.52M → 258B |

**החלטת עיצוב:** Growth שונה פר שדרוג (ולא 1.18 אחיד כבתבנית) — שדרוגים חזקים מתייקרים מהר יותר, מה שמאלץ פיזור תיק במקום התמקדות בשדרוג אחד.

## 3. Pickaxe/Tool Power + Milestone

```
ToolContribution = Level × BaseValue × 1.5^floor(Level/10)
```
כל 10 רמות = מיילסטון ×1.5 קבוע. **✅ אימות:** מקוש רמה 12 → ‎1 + 12×1.5 = ‎19/לחיצה בדיוק.

## 4. Robot Production Formula

```
RobotIncome/sec = Σ [ UnitLvl × BaseRate × 1.5^floor(Lvl/10) ]
                  × Reactor × Crystal × 💠 × PrestigeAuto × Specialty × Rush
```
BaseRate: כורה 1/s · רחפן 8/s · צי 60/s.

## 5. Coins Per Second (CPS)

```
CPS = ManualIncome (perClick × קצב-לחיצות-נמדד)
    + RobotIncome (perSec)
    + InvestmentIncome (יתרות בורסה × תשואה)
```
קצב הלחיצות נמדד בממוצע נע (cpsEst) — משמש גם את יועץ ה-AI לחישובי ROI.

## 6. Offline Income

```
OfflineCoins = CPS × min(AwaySeconds, 14,400) × 0.6
```
**עודכן בפרק זה:** תקרה הועלתה מ-2 ל-**4 שעות**, יעילות מ-50% ל-**60%** (החזר-שחקנים). בנוסף: קופת הגמל ממשיכה ריבית דריבית אופליין עד ×2.

## 7–8. Critical Chance & Damage

```
CritChance = 10% (קבוע בגרסה הנוכחית)
CritReward = NormalCoins × 3
```
🔮 שדרוגי Crit Chance/Damage שמורים לעץ הכישורים (פרק עתידי) — לפי Gap Analysis של פרק 3.

## 9. Combo System ✨ חדש

```
ComboBonus = 1 + min(ComboCount, 100) × 0.01     (תקרה: ×2)
חלון קומבו: 1.5 שניות בין לחיצות; איפוס בחריגה
```
מוצג חי מעל רובי: "🔥 קומבו ×N (+N%)" — צבע וגודל גדלים עם הרצף (זהב→כתום→אדום מ-50).
**✅ אימות:** 25 לחיצות רצופות → ×1.25 בדיוק; איפוס אחרי 1.5 שנ' ✓.

## 10. Lucky Drop ✨ חדש

```
LuckyChance = 5% מכל לחיצה
תוצאות:  60% → מטבעות ×2 על אותה לחיצה (מצטבר עם קריט!)
         30% → אנרגיה מלאה ⚡
         10% → אוצר: 5 דקות הכנסה פסיבית + 50 לחיצות 💰
```
בנוסף קיימים: משאב נדיר מעבודת רובי (18%, ×4) וכוכב הזהב ⭐ (×25).

## 11. Prestige Formula ✨ חדש

```
💠 PrestigeCrystals = floor( √(LifetimeCoins ÷ 100,000) )
כל קריסטל = +2% לכל ההכנסות, לנצח, בכל הכוכבים
נטענים אוטומטית בנחיתה על כוכב חדש
```
| Lifetime | 💠 | בונוס מצטבר |
|---|---|---|
| 100K | 1 | +2% |
| 1M | 3 | +6% |
| 100M | 31 | +62% |
| 1B | 100 | +200% (×3) |

**✅ אימות:** ‎1M → 3 קריסטלים, מכפיל 1.06 בדיוק. שכבה זו מתווספת לבונוסי הכוכבים הקיימים (×2 לחיצה / ×2 אוטו / ×1.5 הכול) — Prestige כפול-רובד: בחירה אסטרטגית + צבירה מתמטית.

## 12. Research Cost

🔮 `Cost = Base × 1.35^Level` — שמור לעץ הכישורים. לא מיושם עד שתהיה מערכת שצורכת אותו (עקרון פרק 3).

## 13. World Unlock Formula

```
TravelThreshold = 120,000 × 10^PlanetsVisited
CrackThreshold  = 20,000 × 10^PlanetsVisited
כל המחירים בכוכב חדש: ×10
```
**החלטה:** ×10 (ולא ×6 כבתבנית) כי הבונוסים אצלנו מכפילים (×2) ולא מוסיפים אחוזים — נבדק שקצב ההגעה ל-Prestige נשאר בטווח היעד.

## 14. Daily Reward ✨ חדש

```
DailyReward = max(200×ScaleFactor, CPS × 60 × Minutes[streak])
Minutes = [30, 45, 60, 90, 120, 180, 240]  (ימים 1–7+)
יום 7, 14, 21... → תיבת שבוע 🎁 = הפרס ×2
רצף נשבר אם דילגת יום
```
**✅ אימות:** יום 7 עם הכנסה פעילה → "תיבת שבוע — כפול! +153K (240 דקות הכנסה)"; אין כפל באותו יום ✓; מוצג אחרי פופ-אפ האופליין, לא במקביל ✓.

## 15. Advertisement Reward

❌ **החלטה מודעת: אין פרסומות בגרסה הנוכחית.** המשחק חינמי ואופליין. אם יתווספו בעתיד — Rewarded בלבד, Opt-in, לפי העקרונות שנקבעו בפרק 2 (שאלות העסק). הנוסחה שמורה: `AdBonus = Income × 2 למשך 15 דק'`.

## 16. Difficulty Curve (זמן לשדרוג הבא)

| שלב | יעד תבנית | בפועל אצלנו |
|---|---|---|
| Early | 15–30 שנ' | ✅ ~15 שנ' (מקוש 15, ‎1+/לחיצה) |
| Early-Mid | 30–90 שנ' | ✅ רובוט 60, כור 500 |
| Mid | 1–3 דק' | ✅ רחפן 3K עם CPS ~20 |
| Late-Mid | 3–8 דק' | ✅ מקדחה 12K, צי 75K |
| End | 8–20 דק' | ✅ מיילסטונים גבוהים + כוכב הבא ×10 |

## 17. Economy Balancing Rules — סטטוס

| כלל | סטטוס |
|---|---|
| ROI לכל שדרוג בטווח 2–10 דק' בשלבים הראשונים | ✅ נאכף חי ע"י יועץ ה-AI (מציג החזר בשניות; רובוט ראשון = 60 שנ') |
| אוטומציה לא עוקפת ידני בתחילת המשחק | ✅ רובוט ראשון 1/s מול ~1–3/לחיצה + קומבו + קריט; ידני מוביל עד ~עידן התעשייה |
| עולם חדש = קפיצת הכנסה מורגשת | ✅ מכפיל בחירה + 💠 + מיילסטונים נשמרים ברמת רובי |
| Prestige מורגש אך לא מייתר את ההתחלה | ✅ ×10 עלויות מול מכפילים ×2–3 → ההתחלה מהירה יותר אך לא טריוויאלית |

## הערה מקצועית — איך נאזן בפועל

הקבועים (1.35, ×10, 5%, 0.02...) הם **גרסת בסיס לבדיקה**. תהליך האיזון: (1) טלמטריה בסיסית של זמני אבן-דרך (Should Have), (2) השוואה ליעדי ה-KPI מפרק 3, (3) כיוון קבוע אחד בכל פעם. יתרון הארכיטקטורה: כל הקבועים מרוכזים בראש הקובץ — שינוי איזון = שינוי שורה אחת.
