## ✨ חדש בפרק זה

1. **תור כרזות (Banner Queue)** — עד כה אירועים בו-זמניים (מיילסטון+סינרגיה+דרגה) דרסו זה את זה והשחקן איבד מידע. עכשיו: תור עד 3 (הטריות נשמרות), הצגה סדרתית 2.6 שנ' + מרווח 350ms. **✅ אומת:** שלוש כרזות בבת אחת → מוצגות 1→2→3.
2. **רצף היכרות FTUE** — שחקן חדש: "היי! אני רובי! 🤖" (0.9 שנ') → אם טרם לחץ: "הכוכב הזה מלא אוצרות — לחץ עליו! ⛏️" (4.6 שנ') → אחרי רכישה ראשונה: "מעולה! ככה בונים אימפריה! 🚀". show-don't-tell: אפס מסכי הדרכה, הדמות היא המדריך. **✅ אומת.**

## עומק ניווט — כלל 2 הנגיעות

כל פעולה במשחק במרחק ≤2 נגיעות: כרייה=0 · קנייה=2 (לשונית+כרטיס) · השקעה=2 (📈+הפקד) · כישור=2. אין תפריטים מקוננים.

## מדרג קשב (Attention Hierarchy)

| ערוץ | תפקיד | משך |
|---|---|---|
| חלון מודאלי | דורש החלטה (מתנה, מסע) | עד סגירה |
| כרזה (תור) | הישג/אירוע | 2.6 שנ' |
| בועת רובי | אישיות + טיפים | 2–4.5 שנ' |
| תג אדום | "יש משהו בשבילך" | עד טיפול |
| מספר צף | אישור פעולה | ~1 שנ' |
| פעימת זוהר | "אפשר לקנות" | קבוע |

כלל: לעולם לא שני מודאלים — האופליין והיומי משורשרים; מתנה חוסמת אירועים אחרים.

## מלאי מצבי UI (States)

- **כרטיס שדרוג:** נעול-נסתר → נעול-נראה (???) → cant (אפור) → ready (פועם זהב) → נקנה (רמה+פס).
- **כפתור:** רגיל → hover(scale) → active(3D press) → disabled(.45) → focus-visible(מסגרת).
- **משימה:** בחירה-בין-2 → פעילה(פס 8%+) → מוכנה(פועם) → נאספה.
- **סינרגיה/תואר/עתיקה:** נסתר/נעול(מעומעם+רמז) → פעיל(צבע) → לבוש(✔).
- **בורסה:** תשואה ↑ירוק/↓אדום · מושקע/ריק · חדשות אירוע.

## זרימות מפתח (Flows)

1. **FTUE (0–60 שנ'):** ברכת רובי → לחיצה → +1 צף → 15 שנ': מקוש ready פועם → קנייה → "ככה בונים אימפריה!" → משימה ראשונה מוצגת. אפס חלונות.
2. **סשן חוזר:** אופליין 💰 → בונוס יומי 📅 (משורשר) → תגים אדומים מציגים מה חדש → 3 יומיות חדשות.
3. **Prestige:** תג 🚀 → לשונית כוכב → כרטיס מסע → **אישור שקוף** → סצנה → בחירת ביומה (יתרון/חיסרון) → נחיתה → "בית חדש!".

## עקרונות שנאכפו (הפניה לכרך)

Fitts (יעדים ≥40–58px) · Hick (4 לשוניות) · Miller (5 גלולות) · Jakob (דפוסי idle מוכרים) · Peak-End · Zeigarnik (8%) · Von Restorff (מסע פועם) · Doherty (<400ms הכול) · פידבק <100ms · RTL מלא · Reduced-Motion · ניגודיות AA.
